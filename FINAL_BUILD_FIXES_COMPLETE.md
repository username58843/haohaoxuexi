**Решение:** Перемещены комментарии ВНУТРЬ useEffect, прямо перед закрывающей скобкой с зависимостями:

```javascript
// ❌ НЕПРАВИЛЬНО:
// eslint-disable-next-line react-hooks/exhaustive-deps
useEffect(() => {
  // код
}, [deps])

// ✅ ПРАВИЛЬНО:
useEffect(() => {
  // код
// eslint-disable-next-line react-hooks/exhaustive-deps
}, [deps])
```

**Исправлено для обоих useEffect:**
- ✅ Загрузка персонального словаря
- ✅ Загрузка словарей для конфига
