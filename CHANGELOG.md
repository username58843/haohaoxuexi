# Changelog - Новые функции

## Добавленные функции

### 1. ✅ Поиск по словарю
- Страница `/search` с полнотекстовым поиском
- Детальная информация о каждом слове:
  - Китайские иероглифы (упрощенные и традиционные)
  - Пиньинь
  - Перевод на английский
  - SVG анимация написания иероглифов (stroke order)
  - Звуковое произношение (Web Speech API)
  - Примеры предложений (6 для бесплатных, 10 для премиум)

### 2. ✅ Переводчик текстов
- Страница `/translate`
- Поддержка языков: Китайский, Русский, Английский, Туркменский
- Два режима перевода:
  - ИИ перевод (OpenAI GPT) - по умолчанию
  - Машинный перевод (MyMemory API) - резервный
- Двусторонний перевод

### 3. ✅ Лендинг страница
- Страница `/landing`
- Современный дизайн с темной темой
- Описание всех функций
- Сравнение бесплатных и премиум возможностей
- Адаптивный дизайн для всех устройств

### 4. ✅ Система аккаунтов
- Регистрация через email с капчей (Google reCAPTCHA)
- Вход в систему
- Профиль пользователя (`/profile`):
  - Изменение имени
  - Изменение пароля
  - История поиска
- Личные данные пользователя
- Система премиум подписок

### 5. ✅ Админ-панель
- Страница `/admin` (только для администраторов)
- Управление пользователями:
  - Просмотр всех пользователей
  - Редактирование пользователей
  - Назначение премиум подписок
  - Назначение администраторов
  - Удаление пользователей

### 6. ✅ Темная тема
- Применена по умолчанию ко всему приложению
- Современный темный дизайн
- Адаптивная цветовая схема

### 7. ✅ Обновленная навигация
- Новое меню с ссылками на все страницы
- Выпадающее меню пользователя
- Индикатор премиум статуса
- Быстрый доступ к профилю и админ-панели

## Технические изменения

### База данных
- Подключение к MongoDB (MongoDB Atlas для продакшена)
- Модель пользователя с полями:
  - email, password (хэшированный), name
  - isPremium, premiumExpiresAt
  - isAdmin
  - personalDictionaries
  - searchHistory
  - createdAt, updatedAt

### API Routes
- `/api/auth/*` - Аутентификация
- `/api/search/*` - Поиск по словарю
- `/api/translate` - Переводчик
- `/api/user/*` - Управление профилем
- `/api/admin/*` - Админ функции

### Безопасность
- Хэширование паролей (bcryptjs)
- JWT токены для аутентификации
- Google reCAPTCHA для защиты от ботов
- Проверка прав доступа для админ функций

### Новые зависимости
- `mongodb` - Работа с MongoDB
- `bcryptjs` - Хэширование паролей
- `jsonwebtoken` - JWT токены
- `axios` - HTTP запросы
- `react-google-recaptcha` - Google reCAPTCHA

## Что нужно сделать перед запуском

1. Установить зависимости: `npm install`
2. Создать `.env.local` с переменными окружения
3. Настроить MongoDB Atlas
4. Настроить Google reCAPTCHA
5. Запустить: `npm run dev`
6. Создать первого администратора через MongoDB

## Примечания

- Все старые функции сохранены и работают
- Темная тема применена по умолчанию
- Для работы ИИ перевода нужен OpenAI API ключ (опционально)
- Для работы на Vercel нужен MongoDB Atlas (бесплатный план доступен)
