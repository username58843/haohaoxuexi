# 🛠️ Как стать администратором

## 🚀 Быстрый способ

1. **Войдите в свой аккаунт**
2. **Перейдите в профиль** (`/profile`)
3. **Найдите раздел "Administrator Access"**
4. **Нажмите кнопку "Become Admin"**
5. **Готово!** Теперь у вас есть права администратора

## 📋 Что дает статус администратора

- ✅ Доступ к панели администратора (`/admin`)
- ✅ Управление всеми пользователями
- ✅ Просмотр статистики
- ✅ Возможность изменять роли пользователей

## 🔧 Технические детали

- Система проверяет, что пользователь еще не является админом
- Изменения сохраняются в базе данных MongoDB
- Статус обновляется автоматически после нажатия кнопки
- Безопасно: только текущий пользователь может сделать себя админом

## 🎯 После получения прав

1. Перезагрузите страницу (или выйдите и войдите снова)
2. В меню появится пункт "Admin Panel"
3. Перейдите в `/admin` для управления системой
