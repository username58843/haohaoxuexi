# Руководство по обновлению до Next.js 15

## Что было обновлено

### Основные зависимости
- **Next.js**: 9.3.5 → 15.0.3
- **React**: 16.13.1 → 18.3.1
- **React DOM**: 16.13.1 → 18.3.1
- **Bootstrap**: 4.4.1 → 5.3.3
- **MongoDB**: 6.3.0 → 6.10.0
- **Axios**: 1.6.2 → 1.7.7
- **React Hook Form**: 5.5.3 → 7.53.0
- **Reactstrap**: 8.4.1 → 9.2.2

### Изменения в коде

1. **Bootstrap классы обновлены**:
   - `ml-auto` → `ms-auto` (margin-left → margin-start)
   - `mr-*` → `me-*` (margin-right → margin-end)
   - `ml-*` → `ms-*` (margin-left → margin-start)
   - `float-left` → `float-start`
   - `right` prop в DropdownMenu → `end`

2. **Next.js конфигурация**:
   - Добавлен `reactStrictMode: true`
   - Добавлен `swcMinify: true`
   - Добавлен `serverComponentsExternalPackages` для MongoDB и bcryptjs

3. **ESLint**:
   - Обновлен до использования `next/core-web-vitals`
   - Удалены старые конфигурации

4. **Стили**:
   - Обновлен импорт Bootstrap до версии 5
   - Удален импорт `bs.scss` (если был)

## Что нужно сделать после обновления

### 1. Удалите старые зависимости

```bash
rm -rf node_modules package-lock.json yarn.lock
```

### 2. Установите новые зависимости

```bash
npm install
# или
yarn install
```

### 3. Проверьте переменные окружения

Убедитесь что файл `.env.local` содержит все необходимые переменные:

```env
MONGODB_URI=your-mongodb-uri
JWT_SECRET=your-secret-key
NEXT_PUBLIC_RECAPTCHA_SITE_KEY=your-site-key
RECAPTCHA_SECRET_KEY=your-secret-key
OPENAI_API_KEY=your-openai-key (optional)
```

### 4. Запустите приложение

```bash
npm run dev
```

### 5. Проверьте работу

- [ ] Приложение запускается без ошибок
- [ ] Страницы загружаются корректно
- [ ] API routes работают
- [ ] Аутентификация работает
- [ ] Поиск работает
- [ ] Переводчик работает
- [ ] Админ-панель работает

## Возможные проблемы и решения

### Проблема: Ошибки сборки на Vercel

**Решение**: 
1. Убедитесь что Node.js версия >= 18.0.0 в `package.json` (уже добавлено)
2. Проверьте что все переменные окружения установлены в Vercel
3. Очистите кэш Vercel и пересоберите проект

### Проблема: Ошибки с Bootstrap классами

**Решение**: Все классы Bootstrap 4 уже обновлены на Bootstrap 5. Если видите ошибки, проверьте что Bootstrap 5 правильно импортирован в `_app.js`

### Проблема: Ошибки с MongoDB

**Решение**: 
1. Убедитесь что `MONGODB_URI` правильно установлен
2. Проверьте что MongoDB Atlas доступен
3. Убедитесь что IP адреса добавлены в белый список

### Проблема: Ошибки с React Hook Form

**Решение**: API React Hook Form 7 совместим с предыдущими версиями. Если есть проблемы, проверьте что все формы используют правильный синтаксис.
