# ✅ Исправление загрузки словарей по умолчанию

## 🐛 Найденная проблема:

### **Бесконечная загрузка "Loading dictionary..." для HSK словарей**
- **Симптом:** При выборе HSK словарей показывалось "Loading dictionary..." бесконечно
- **Причина:** Неправильная логика обработки состояния загрузки и данных

### **Корень проблемы:**
1. `data` возвращал `[]` (пустой массив) для незагруженных персональных словарей
2. Условие `if (!data && !loading)` считало пустой массив как отсутствие данных
3. Компонент показывал форму настроек вместо загрузки

## 🔧 Исправления:

### 1. **Изменена логика data в `pages/learn.js`:**
```javascript
// ✅ Обычные словари обрабатываются сразу
if (regularLevels.length > 0) {
  let result = shuffle(allData.flat())
  if (configObject.wordsLimit > 0) {
    result = result.slice(0, configObject.wordsLimit)
  }
  return result // Возвращаем данные сразу
}

// ✅ Персональные словари: показываем загрузку пока не загрузятся
if (personalLevels.length > 0 && Object.keys(userDictionaries).length === 0) {
  return null // Показываем загрузку (не [])
}

// ✅ Персональные словари: возвращаем данные когда загружены
if (personalLevels.length > 0 && Object.keys(userDictionaries).length > 0) {
  let result = shuffle(allData.flat())
  if (configObject.wordsLimit > 0) {
    result = result.slice(0, configObject.wordsLimit)
  }
  return result
}
```

### 2. **Исправлена логика отображения компонентов:**
```javascript
// ✅ Показываем загрузку если данные еще не готовы
if (loading && !data) {
  return (
    <div className="text-center" style={{ padding: '50px', color: '#fff' }}>
      <div style={{ fontSize: '1.2rem', marginBottom: '20px' }}>Loading dictionary...</div>
      <div className="spinner-border text-primary" role="status">
        <span className="visually-hidden">Loading...</span>
      </div>
    </div>
  )
}

// ✅ Показываем форму только если действительно нет данных
if (!data && !loading) {
  // Форма настроек
}
```

### 3. **Улучшено управление состоянием загрузки:**
```javascript
useEffect(() => {
  if (configObject && user) {
    setLoading(true) // Показываем загрузку при изменении config
    loadUserDictionariesForConfig()
  } else if (!configObject) {
    setLoading(false) // Нет config - нет загрузки
  }
}, [configObject, user, loadUserDictionariesForConfig])
```
