# ✅ Исправление загрузки словарей по умолчанию (v2)

## 🐛 Найденная проблема:
**Функция `sample(config.modes)` падала с ошибкой**, когда `config.modes` был `undefined`.

### **Корень проблемы:**
1. В `lib/learn.js` функция `buildFromConfig` использовала `sample(config.modes)` без проверки
2. В `pages/learn.js` аналогичная проблема в некоторых местах
3. Когда пользователь выбирал HSK словари, `config.modes` мог быть `undefined`
4. Это вызывало JavaScript ошибку → "Loading dictionary..." бесконечно

## 🔧 Исправления:

### 1. **Исправлен `lib/learn.js`:**
```javascript
// ✅ Было:
type: sample(config.modes),

// ✅ Стало:
type: sample(config.modes || ['characters-pinyin']),
```

### 2. **Исправлен `pages/learn.js`:**
```javascript
// ✅ Добавлены проверки везде:
type: sample(configObject.modes || ['characters-pinyin']),
```

### 3. **Исправлена синтаксическая ошибка:**
```javascript
// ✅ Убрана лишняя закрывающая скобка в buildFromConfig
```

## 🎯 **Результат:**
- ✅ **HSK словари работают сразу** - выбираете → обучение стартует
- ✅ **Нет JavaScript ошибок** - правильные fallback значения
- ✅ **Линтер прошел** ✅

## 🚀 **Как проверить:**
1. Перейдите в **学习** (Learn)
2. Выберите **HSK словари** (hsk1, hsk2, etc.)
3. **Обучение должно начаться сразу!** 🎉
