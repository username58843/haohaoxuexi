# Полная инструкция по установке и использованию

## 🚀 Быстрый старт

### Шаг 1: Установка зависимостей

```bash
npm install
# или
yarn install
```

### Шаг 2: Настройка переменных окружения

Создайте файл `.env.local` в корне проекта со следующим содержимым:

```env
# MongoDB - обязательно
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/hsk-app?retryWrites=true&w=majority

# JWT Secret - обязательно (измените на случайную строку)
JWT_SECRET=ваш-случайный-секретный-ключ-минимум-32-символа

# Google reCAPTCHA - обязательно
NEXT_PUBLIC_RECAPTCHA_SITE_KEY=ваш-site-key
RECAPTCHA_SECRET_KEY=ваш-secret-key

# OpenAI API (опционально, для ИИ перевода)
OPENAI_API_KEY=sk-ваш-openai-key
```

### Шаг 3: Настройка MongoDB Atlas (для Vercel)

1. Зайдите на [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)
2. Создайте бесплатный аккаунт
3. Создайте новый кластер (выберите бесплатный план M0)
4. Создайте пользователя базы данных:
   - Database Access → Add New Database User
   - Username и Password (сохраните их!)
5. Настройте сетевой доступ:
   - Network Access → Add IP Address
   - Добавьте `0.0.0.0/0` (разрешает все IP адреса)
6. Получите строку подключения:
   - Clusters → Connect → Connect your application
   - Скопируйте connection string
   - Замените `<password>` на ваш пароль
   - Добавьте в `.env.local` как `MONGODB_URI`

### Шаг 4: Настройка Google reCAPTCHA

1. Зайдите на [Google reCAPTCHA Admin](https://www.google.com/recaptcha/admin)
2. Нажмите "+" для создания нового сайта
3. Заполните форму:
   - Label: HSK Learning Platform
   - reCAPTCHA type: reCAPTCHA v2 → "I'm not a robot" Checkbox
   - Domains: добавьте `localhost` (для разработки) и ваш домен Vercel
4. Примите условия и отправьте
5. Скопируйте Site Key и Secret Key в `.env.local`

### Шаг 5: Запуск приложения

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## 📦 Развертывание на Vercel

### Шаг 1: Подготовка репозитория

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ваш-username/ваш-репозиторий.git
git push -u origin main
```

### Шаг 2: Развертывание на Vercel

1. Зайдите на [Vercel](https://vercel.com)
2. Войдите через GitHub
3. Нажмите "New Project"
4. Импортируйте ваш репозиторий
5. В настройках проекта добавьте переменные окружения:
   - `MONGODB_URI` - ваша строка подключения MongoDB Atlas
   - `JWT_SECRET` - случайный секретный ключ
   - `NEXT_PUBLIC_RECAPTCHA_SITE_KEY` - публичный ключ reCAPTCHA
   - `RECAPTCHA_SECRET_KEY` - секретный ключ reCAPTCHA
   - `OPENAI_API_KEY` - ключ OpenAI (опционально)
6. Нажмите "Deploy"

### Шаг 3: Обновление reCAPTCHA

После получения домена Vercel:
1. Зайдите в Google reCAPTCHA Admin
2. Добавьте ваш домен Vercel в список доменов
3. Сохраните изменения

### Шаг 4: Создание первого администратора

После развертывания:

1. Зарегистрируйтесь через сайт
2. Подключитесь к MongoDB Atlas через MongoDB Compass или веб-интерфейс
3. Найдите вашу базу данных и коллекцию `users`
4. Найдите документ с вашим email
5. Обновите поле `isAdmin` на `true`:

```javascript
db.users.updateOne(
  { email: "ваш-email@example.com" },
  { $set: { isAdmin: true } }
)
```

Или через MongoDB Compass:
- Найдите документ пользователя
- Измените `isAdmin` с `false` на `true`
- Сохраните изменения

## 🔧 API Endpoints

### Аутентификация
- `POST /api/auth/register` - Регистрация нового пользователя
- `POST /api/auth/login` - Вход пользователя
- `GET /api/auth/me` - Получить текущего пользователя
- `POST /api/auth/logout` - Выход пользователя

### Поиск
- `GET /api/search?q=...` - Поиск по словарю
- `GET /api/search/examples?word=...` - Получить примеры предложений

### Перевод
- `POST /api/translate` - Перевести текст
  - Body: `{ text, from, to, useAI }`

### Пользователь
- `PUT /api/user/profile` - Обновить профиль
- `PUT /api/user/password` - Изменить пароль

### Админ (требуется авторизация администратора)
- `GET /api/admin/users` - Получить всех пользователей
- `PUT /api/admin/users/[id]` - Обновить пользователя
- `DELETE /api/admin/users/[id]` - Удалить пользователя

## 🐛 Устранение неполадок

### Ошибка подключения к MongoDB
- Проверьте `MONGODB_URI` в `.env.local`
- Убедитесь что MongoDB Atlas кластер запущен
- Проверьте что ваш IP добавлен в белый список (или используйте 0.0.0.0/0)
- Проверьте правильность username и password в connection string

### Ошибка reCAPTCHA
- Проверьте что ключи правильно добавлены в `.env.local`
- Убедитесь что домен добавлен в настройках reCAPTCHA
- Для локальной разработки используйте тестовый ключ: `6LeIxAcTAAAAAJcZVRqyHh71UMIEGNQ_MXjiZKhI`

### Ошибки сборки
- Убедитесь что все зависимости установлены: `npm install`
- Проверьте версию Node.js (требуется 14+): `node --version`
- Очистите кэш: `rm -rf .next node_modules && npm install`

### Ошибки аутентификации
- Проверьте что `JWT_SECRET` установлен в `.env.local`
- Убедитесь что cookies работают (проверьте настройки браузера)
- Проверьте что токен правильно передается в заголовках

### Переводчик не работает
- Если используется OpenAI, проверьте что `OPENAI_API_KEY` установлен
- Проверьте баланс на аккаунте OpenAI
- Переводчик автоматически переключится на машинный перевод если OpenAI недоступен
