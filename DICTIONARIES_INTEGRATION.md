## 🚀 Как использовать:

### Создание пользовательского словаря:
1. Перейти в **Dictionary Search**
2. Найти нужные слова
3. Нажать **"Add to Selected Words"** на интересующие слова
4. Когда накопится достаточно слов → **"Create from Selected Words"**
5. Дать имя словарю

### Использование в обучении:
1. Перейти в **学习** (Learn)
2. Выбрать нужные словари (пользовательские показываются первыми)
3. **Изменить порядок** с помощью кнопок ↑↓ если нужно
4. Нажать **"Start Learning"**

### Управление словарями:
1. Перейти в **My Dictionaries** (ссылка в настройках обучения)
2. Создавать, редактировать, удалять словари
3. Управлять выбранными словами
